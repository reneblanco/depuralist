# DepuraList

Free tool to pre-filter email lists from Excel before importing them into your email platform, processed locally in the browser. Includes landing pages per platform (Mailchimp, HubSpot, Brevo, Klaviyo and more).

**Live:** [depuralist.com](https://depuralist.com)

Designed and product-led by René Blanco, built with AI-assisted development tools. Static site deployed on Netlify.
